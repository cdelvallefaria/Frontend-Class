# Luz y Momentos | Portafolio de Fotografía

Página web sencilla de portafolio fotográfico, creada con **HTML** y **CSS** como parte del laboratorio de herramientas de Desarrollo Web.

## Descripción
El proyecto muestra una galería de fotografías, una sección "Sobre mí" y un apartado de contacto. Además, sirve para practicar el flujo de trabajo con **Git**, **GitHub** y **Visual Studio Code**.

## Tecnologías utilizadas
- HTML5
- CSS3 (Grid, Flexbox y transiciones)
- Git y GitHub
- Visual Studio Code con la extensión Live Server

## Estructura del proyecto
```
portafolio-fotografia/
├── index.html
├── style.css
├── README.md
└── img/
    ├── foto1.jpg
    ├── foto2.jpg
    └── ...
```

## Cómo ver la página
1. Clona el repositorio:
   ```
   git clone https://github.com/cdelvallefaria/portafolio-fotografia.git
   ```
2. Abre la carpeta en Visual Studio Code.
3. Haz clic derecho en `index.html` y elige **Open with Live Server**.

También puedes abrir `index.html` directamente en tu navegador.
