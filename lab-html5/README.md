DESCRIPCIÓN DE LA TAREA
--------------------------------------------------
Este laboratorio consiste en crear la estructura básica de una página
web usando HTML5, desarrollada en Visual Studio Code, visualizada en el
navegador y guardada en un repositorio de GitHub.

Para el proyecto desarrollé una página con temática navideña, titulada
"¡Llegó la Navidad!", que aplica los tres puntos que pide el laboratorio:

1. SINTAXIS DE HTML
   - Etiquetas de apertura y cierre: <html>, <head>, <body>
   - Encabezados (<h1>, <h2>, <h3>), párrafos (<p>), listas (<ul>, <li>)
     y enlaces (<a href="...">)
   - Atributos y valores: lang, charset, src, alt, href, controls

2. SEMÁNTICA DE HTML
   - Etiquetas semánticas: <header>, <nav>, <main>, <section>,
     <article>, <aside> y <footer>
   - Cada una describe el significado del contenido, lo que mejora la
     accesibilidad, el SEO y la legibilidad del código.

3. CARACTERÍSTICAS DE HTML5
   - <figure> y <figcaption>: imagen con su descripción
   - <video>: video con controles, sin necesidad de plugins
   - <audio>: música navideña con controles
   - <canvas>: dibujo de un árbol de Navidad con JavaScript

Los comentarios dentro del código (index.html) explican las
características principales de la estructura de HTML5 y sus ventajas
frente a versiones anteriores: multimedia nativa sin plugins, mejor SEO,
mayor accesibilidad, código más limpio y compatibilidad con móviles.
